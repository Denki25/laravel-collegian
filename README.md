# CLSU Collegian Content Guide

This repo holds the static content files for the CLSU Collegian site.

Start here:

- [UPDATE_GUIDE.md](UPDATE_GUIDE.md) for step-by-step instructions on updating articles, issues, and multimedia
- [LARAVEL_MIGRATION.md](LARAVEL_MIGRATION.md) for the Laravel version of the site

Main content files:

- `public/data/articles/`
- `public/data/issues.js`
- `public/data/multimedia.js`
- `public/data/site-config.js`

If you are editing the Laravel copy, use the same file structure inside `collegian-laravel/public/data/`.
